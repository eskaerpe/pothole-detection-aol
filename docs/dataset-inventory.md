# Dataset inventory and curation

The three supplied source URLs are listed below. Their order is not proof of the local folder-to-source mapping. Match publication filenames, content and version before treating the mapping as confirmed:

1. https://data.mendeley.com/datasets/5bwfg4v4cd/3
2. https://data.mendeley.com/datasets/tp95cdvgm8/1
3. https://universe.roboflow.com/cv-y6ho5/dash-cam-pothole-detection-uplo2-2puab/browse?queryText=&pageSize=100&startingIndex=0&browseQuery=true

`dataset_1`, `dataset_2`, and `dataset_3` are untouched raw inputs. The catalog generated by `python3 scripts/inventory_datasets.py` is local at `datasets/curation-v1/` and is Git-ignored. It refuses to overwrite an existing catalog. Paths in CSV files are relative to the repository root; they index original files rather than copy or modify them.

- `files.csv`: path, size and SHA-256 for each raw file, including archives and metadata; archives are not extracted.
- `dataset_1_video_pairs.csv`: RGB/mask paths by original split and filename.
- `dataset_2_index.csv`: image, matching YOLO and XML paths, exact-image hash, duplicate group size and annotation validation issues.
- `dataset_2_duplicate_images.csv`: byte-identical image groups, not perceptual duplicates.
- `summary.json`: counts and aggregate warnings.

## Usage decisions

- **dataset_1:** 619 RGB/mask video name pairs, none missing by name. Segmentation masks are not YOLO bounding boxes. Visual content and ground-truth quality remain unverified. Original splits do not establish independence from the pretrained model.
- **dataset_2:** 713 image/YOLO/XML records. Four YOLO files have invalid box bounds: Pothole-261, 262, 268 and 271. There are 36 exact duplicate groups containing 50 extra copies. Duplicates have not been removed; annotation agreement and source-video grouping remain to be reviewed. XML also contains an `o` label that requires review. Do not train from the raw folder or treat it as an independent benchmark until provenance and annotation quality are resolved. Front and rear dashcam videos are candidates for inspection, not verified independent test footage.
- **dataset_3:** 1,244 images, but the export README explicitly says annotation data was not included. Empty labels are not verified pothole-free images. Re-export the `Pothole` annotation group if accessible and allowed; otherwise annotate manually. The Roboflow public project page states BY-NC-SA 4.0, but verify that this exact export comes from that project and resolve conflicting local `Private` metadata before use or redistribution.

## Next checks

2. Review representative images and videos, including the four invalid boxes and `o` XML label. Correct only in a separate derivative with a decision record.
3. Check labels across duplicate groups before choosing a canonical sample; keep all related or near-duplicate frames in the same split. Do not silently remove originals.
4. Reserve separately collected target phone video and annotations for evaluation. A catalog or an unverified dashcam video is not a performance test.
